A house of brands, run from one desk. A deliberately short roster — models,
actresses, and specialty talent — with clean terms and sharper standards.
Every site in the house carries one aesthetic: obsidian ground, bone ink,
gold worn as foil. The faces stay thin; one machine runs the operation.

## The way this house builds

- **One aesthetic.** Dark luxe — near-black, bone text, serif display, mono eyebrows, thin rules. Gold is foil, never paint. The marks are never redrawn.
- **Faces stay thin.** Public sites read; the MACHINE writes. One database, additive-only, owned in one place.
- **Gates before anything ships.** `pnpm typecheck · lint · build` green, then branch → PR → merge. No exceptions, no stacked breakage.
