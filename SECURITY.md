# Security

If you find a vulnerability in anything this house runs — a site, an API,
a payment lane — report it privately. No public issues, no proof-of-concept
posts.

**Email:** [niko@savagestud.io](mailto:niko@savagestud.io) · subject line
starting with `SECURITY:`

You'll get a reply from the desk, usually within 48 hours. Good-faith
reports are always welcome; we don't pursue researchers who report
responsibly.
